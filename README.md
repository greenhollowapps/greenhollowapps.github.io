# greenhollowapps.github.io

Developer website for IntervalWorkout, served by GitHub Pages at https://greenhollowapps.github.io/.

- `app-ads.txt` authorises AdMob to sell ad inventory for the app. It must stay at the domain root; AdMob crawls `https://greenhollowapps.github.io/app-ads.txt` because this URL is the Play listing's developer website.
- `.nojekyll` serves files as-is.

The privacy policy lives in its own repo, `intervalworkout-privacy`.
